# Website Structure

## 1. Page map (19 pages)

| URL | Generated by | Content source |
|-----|--------------|----------------|
| `index.html` | `write("index.html", …)` in `build.mjs` | `cars` (featured), `reviews`, `faqs`, `locations` |
| `cars/index.html` | `build.mjs` | `cars`, with type filter chips |
| `cars/<slug>.html` (8) | loop over `cars` in `build.mjs` | one entry of `cars`, gallery from `images/cars/angles/` |
| `about.html` | `build.mjs` | copy in `build.mjs`, zones from `locations` |
| `reviews.html` | `build.mjs` | `reviews` |
| `blog/index.html` | `build.mjs` | `posts` |
| `blog/<slug>.html` (6) | loop over `posts` in `build.mjs` | one entry of `posts` |

Navigation (header, mobile menu and footer links) comes from the `NAV` array near the top of `build.mjs`.

## 2. Build pipeline

```
tools/data.mjs  ──┐
                  ├─►  node build.mjs  ──►  *.html, cars/*.html, blog/*.html
build.mjs  ───────┘
```

`build.mjs` imports the data, defines small helpers (`icon`, `stars`, `carCard`, `reviewCard`, `ctaSection`, `pageHead`) and a `layout()` function that wraps every page with the `<head>`, header, mobile menu, footer, WhatsApp float button and script tags. Each page calls `write(path, layout({...}))`. The script prints `built 19 pages` when done.

`layout()` options: `depth` (0 for root, 1 for `cars/` and `blog/`, used to build relative paths), `title`, `desc`, `current` (nav highlight), `body`, `ogImage`, `ld` (JSON-LD schema).

## 3. CSS (`css/styles.css`)

One stylesheet, mobile-first, with breakpoints at 375, 768, 1024 and 1440 px.

- **Tokens** are in `:root` at the top: `--ink` (page background), `--surface` (cards), `--text`, `--text-2`, `--gold` (the orange accent, `#F04400`), `--wa`, `--font-display`, `--font-body`, `--gutter`, `--max`, `--radius`, `--ease`.
- **Sections** are marked with `/* Name */` comments in this order: Buttons, Nav, Hero, Marquee, Car cards, Filters, Page header, Features, Process, Cutout banner, Reviews, Locations, FAQ, CTA, Footer, WhatsApp floating, Car detail.
- **Home hero** (class `.hx`) re-scopes the tokens for its light look, and its styles sit near the end of the file.
- **Fonts:** Cormorant Garamond (display) and Manrope (body), loaded from Google Fonts in `layout()`.

## 4. JavaScript (`js/`)

| File | Role |
|------|------|
| `app.js` | Non-animation behaviour: nav scroll state, mobile menu, car filters, gallery, enquiry form |
| `motion.js` | Anime.js: entrance reveals (`data-reveal`, `data-stagger`, `data-split`), counters, hover effects |
| `flow.js` | Anime.js: fluid blobs, image reveals, FAQ, footer, tilt, page transitions (skips the home hero) |
| `hero.js` | Home hero only (`#hx`): finish swap, tilt, rolling price, gallery, booking card |
| `scroll.js` | GSAP ScrollTrigger: `data-parallax="N"` drift and other scroll-linked motion |
| `anime.esm.min.js`, `gsap.min.js`, `ScrollTrigger.min.js` | Vendored libraries. Don't edit. |

### Motion rules

1. Animate `transform` and `opacity` only.
2. Never let Anime.js and GSAP write transforms to the same element. Anime.js handles entrances and hovers. GSAP handles scroll-linked motion.
3. Respect reduced motion: `<html>` gets the `rm` class and animations are skipped.
4. Don't rename the ids and classes `hero.js` looks up (`#hx`, `#hx-car`, `#hx-stage`, `.hx-*`).
5. Hidden-until-revealed states are set under the `.js` class so the site works without JavaScript.

### Useful HTML attributes

| Attribute | Effect |
|-----------|--------|
| `data-reveal` | Fade/slide in when scrolled into view |
| `data-stagger` | Children reveal one after another |
| `data-split` | Headline splits into characters and animates |
| `data-count="N"` | Number counts up to N |
| `data-parallax="N"` | Element drifts against scroll by depth N |

| File | Used for |

## 6. Data model (`tools/data.mjs`)

- `PHONE`, `PHONE_TEL`, `WA`, `EMAIL`: contact constants
- `cars[]`: `slug, name, price, transmission, seats, fuel, make, type (convertible|suv|luxury), featured, image, blurb`
- `reviews[]`: `name, initial, count, stars, when, text`
- `locations[]`: `slug, name, region (North Goa|South Goa|Airport), text`. These show as location chips and zone text. They do not have their own pages.
- `posts[]`: `slug, title, date (YYYY-MM-DD), description, paras[]`
- `faqs[]`: `[question, answer]` pairs
