# Goa Luxe Drives

Premium static website for a luxury car-rental business in Goa, India. It has 19 pages: home, fleet, eight car detail pages, about, reviews and a blog with six articles. Every enquiry goes to WhatsApp.

- **Theme:** light (cream `#FAF7F2`, white cards, fiery orange `#F04400`, with a dark footer)
- **Motion:** [Anime.js v4](https://animejs.com) for entrances and micro-interactions, [GSAP](https://gsap.com) + ScrollTrigger for scroll-linked effects
- **Stack:** plain HTML, CSS and JavaScript. There is no framework and no runtime dependency. Pages are generated by one Node script.

## Quick start

You need Node.js 18 or newer and, to preview, Python 3 (any static server works).

```bash
node build.mjs                   # regenerate all 19 HTML pages -> "built 19 pages"
python3 -m http.server 8765      # then open http://localhost:8765
```

Run `node build.mjs` after every change to `build.mjs` or `tools/data.mjs`. CSS, JS and image changes need only a browser refresh.

## What lives where

```
build.mjs        Page generator (templates for every page)
tools/data.mjs   Content: contact details, cars, reviews, FAQs, blog posts, locations
css/styles.css   All styling, driven by tokens in :root
js/              Behaviour and animation (see docs/STRUCTURE.md)
images/          Hero, banner and car photos
*.html, cars/, blog/   GENERATED output - do not edit by hand
```

> The `.html` files are overwritten on every build. Edit `tools/data.mjs` or `build.mjs` instead.

## Deploying

The site is fully static. Upload the project folder (excluding `docs/`, `tools/`, `build.mjs` if you like) to any static host: Netlify, Vercel, GitHub Pages, Cloudflare Pages or plain shared hosting. No build step is needed on the host because the generated HTML is committed.
